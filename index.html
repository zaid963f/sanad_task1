Field Execution

Capture standards that guarantee clean data

Run this checklist before every scan. It takes 90 seconds and prevents 90% of re-shoots.

✓

Keep 0.5–1.5 m scanning distance

Stay inside the optimal range band — closer than 0.5 m distorts geometry; beyond 1.5 m thins the point cloud.

✓

Walk a closed loop route

Plan a circular path that returns to the start point so the point cloud can close its loop alignment.

✓

Hold the scanner steady & level

Keep the device upright and move smoothly — jerky rotations create alignment drift between frames.

✓

Avoid glass & mirrored surfaces

Reflective surfaces return no depth data. Mark them in the console and fill gaps from another angle.

✓

Scan with even, ambient light

Strong backlight and flickering light degrade texture capture. Prefer diffuse daylight or constant lighting.

✓

Verify live preview continuously

Glance at the preview every few seconds — grey “dead zones” should be re-scanned immediately, not later.

Troubleshooting

FAQ for first-time users

Diagnosis, action path, and a deep-link to the full guide for every common issue.

The scanner won't pair with my phone

Diagnosis: the device is on a different network band, or a previous pairing session is stale.

Action: put both devices on the same 2.4 GHz network, toggle Galois Wi-Fi off and on, then retry pairing from the console app.

Deep-link: Connection setup in the full guide →
My point cloud has holes and drift

Diagnosis: route didn't close, or the scanner was moved too quickly through feature-poor areas like blank hallways.

Action: re-scan the affected segment walking a closed loop, keep the device level, and add visual anchors (posters, furniture) where surfaces are bare.

Deep-link: Capture standards section →
The uploaded space looks blurry on web

Diagnosis: texture compression was applied to a low-light capture, or an outdated app version exported at reduced quality.

Action: update the console app, re-export with "Original quality" enabled, and re-upload under clear, even lighting conditions.

Deep-link: Export & upload settings →
Upload stuck at "processing"

Diagnosis: the project exceeds the cloud quota, or the connection dropped mid-transfer.

Action: check quota in Workspace → Storage, switch to a stable network, and use "Resume upload" — processing restarts where it stopped.

Deep-link: Cloud processing status →
Measurements don't match the real room

Diagnosis: measurement endpoints were snapped to noisy point cloud edges instead of true surfaces.

Action: zoom into the scan, re-anchor endpoints on flat surface regions, and cross-check against a tape measure on a known wall.

Deep-link: Measurement toolkit guide →
